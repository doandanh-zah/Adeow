# Brand — ADEOW

_Status: active_

ADEOW now starts from a stark-minimal white canvas. The product identity should stay in behavior and context memory first, not in heavy chrome.

## Direction

- Archetype: full-screen working canvas
- Density: minimal chrome
- Surface: white plane with near-invisible framing
- Type mood: precise, neutral, technical
- Motion: functional only

## Typography

- Sans: `Manrope`
- Mono: `JetBrains Mono`

## Do

- Keep canvas full-screen and visually quiet
- Keep upstream canvas chrome neutral and secondary
- Use only subtle neutral framing when absolutely needed
- Keep any ADEOW identity lightweight and secondary

## Don't

- No side panels by default
- No dashboard chrome around the canvas
- No gradients or decorative overlays
- No visual competition with the drawing plane
